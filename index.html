Preguntas Frecuentes
¿Es necesario realizar el pago antes de comenzar con el proyecto?

Sí, siempre se debe realizar el pago o anticipo correspondiente antes de iniciar con el diseño, configuración o desarrollo de cualquier servicio para garantizar la reserva del espacio y el inicio inmediato de los trabajos técnicos.

¿Cuánto tiempo toma tener listo mi menú digital o sitio web?

El tiempo de entrega depende de los requerimientos y la configuración específica de cada proyecto; sin embargo, la gran mayoría de los menús y sitios web están listos en un plazo estimado de hasta 72 horas una vez confirmado el pago y recibida la información básica.

¿Cómo actualizo los productos o agoto artículos en el menú digital?

Dispones de una interfaz intuitiva para administrar tus categorías, activar publicaciones o marcar productos como agotados de manera rápida y directa.

¿Qué pasa si necesito ayuda técnica o soporte después de entregar el proyecto?

Contamos con soporte técnico continuo para asegurarnos de que tu plataforma funcione sin interrupciones. Ante cualquier duda o ajuste menor, te atendemos de forma directa por WhatsApp.

¿El servicio incluye el dominio y qué pasa después del primer año?

Sí, el primer año de dominio y hospedaje web viene incluido. Para mantener tu menú digital y la plataforma funcionando de manera continua sin interrupciones, el servicio opera bajo una suscripción que se renueva anualmente.

¿Necesito instalar alguna aplicación especial para ver o administrar el menú?

No. Tanto tus clientes como tú pueden acceder desde cualquier navegador web (celular, tablet o computadora) sin necesidad de descargar ninguna aplicación de la tienda.
